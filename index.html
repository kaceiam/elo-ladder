Instructions for every device

iPhone / iPad

  1. Open this page in Safari.
  2. Tap Share (square with an arrow).
  3. Tap Add to Home Screen, then Add.

Android

  1. Open this page in Chrome.
  2. Tap ⋮ (top right).
  3. Tap Install app (or Add to Home screen).

Windows / Mac — Chrome or Edge

  1. Click the install icon at the right end of the address bar,
  2. or Chrome: ⋮ → Cast, save and share → Install page as app; Edge: ⋯ → Apps → Install this site as an app.

Mac — Safari

  1. Click File in the menu bar.
  2. Click Add to Dock.

What's inside

Bots at every level

Seven chess bots powered by Stockfish 18 — Pebble (400) up to Oracle (2800). Strong bots use Stockfish's calibrated Elo limiter.

Play friends anywhere

Create an invite link, text it, and your browsers connect directly. Clocks, chat, draw offers and rematches.

Real Elo ratings

Every game moves your rating, chess.com-style. Climb from Beginner through Intermediate, Advanced and Master to Grandmaster.

Works everywhere

iPhone, iPad, Android, Windows, Mac and Chromebook. Play in the browser or install it as an app — free.
